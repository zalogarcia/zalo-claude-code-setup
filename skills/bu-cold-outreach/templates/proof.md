# Proof Ledger

**Optional. Nothing in this skill is blocked on it.** Astra's messages carry no proof
numbers at all by design, so an empty ledger changes nothing about a session. This file
exists for Zalo: it is where the facts he is allowed to claim live, so that when he takes
a replied thread over and sends message two, he is quoting a written fact rather than a
remembered one.

The rule that does bind Astra: **no number, client name, timeframe or result appears in
any message Astra writes or sends.** Message one is built on facts about the PROSPECT,
which is what the four part message is for. Astra never adds a row here, and never softens
an empty field into a claim ("we have helped a lot of contractors", "clients typically
see").

## Case study 1

```
authorized:        no
client_name:
trade:
metro:
what_we_built:
went_live:
calls_answered:
jobs_booked:
revenue_recovered:
timeframe:
named_publicly:    no
verbatim_line:
```

`named_publicly` is a separate permission from `authorized`. A client can authorize the
numbers and still not want the company name in a stranger's DM. When it is `no`, the
usable form is the trade and the metro ("a plumbing company in Miami"), never the name.

`verbatim_line` is the one sentence Zalo has approved for use as written. If it is filled,
it is used exactly, not paraphrased into something stronger.

## Standing facts (things true about the product, not about a client)

These describe what the system does, not what it produced for someone, so they are
claimable without a case study. Keep them literal. Anything that becomes a number belongs
in a case study block above.

```
answers_in:        about five seconds
availability:      24/7, calls and texts
books_into:        the calendar
never_quotes:      the bot does not give prices over the phone, only genuinely fixed fees
```

## The three sins this file exists to prevent

1. A number nobody gave us. If Zalo did not write it here, it does not exist.
2. Work claimed before it was done. "I trained a demo on your site" before a demo exists
   is this sin wearing a different hat. Astra's message one never claims a demo.
3. Invented urgency. No capped spots, no closing soon, no "before I move on to the next
   city" unless it is literally true and Zalo said so.
